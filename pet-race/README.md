# 萌寵大賽跑 Pet Dash 3D

冬菇（紅貴賓）、墨墨（英短）、粉粉（美短）的立體賽跑網頁遊戲。玩家選一隻角色操作，另外兩隻由電腦控制。三隻一起衝向 1500 米外的終點，最先衝線者勝出。

## 開啟方法

遊戲使用 ES 模組，必須經網頁伺服器開啟（直接雙擊不能運行）。在倉庫根目錄執行：

```
python3 -m http.server 8000
```

然後開啟 `http://localhost:8000/pet-race/`。Three.js 取自倉庫的 `lib/`，不需要連接網絡。

## 玩法

| 動作 | 電腦 | 手機／平板 |
|---|---|---|
| 左右移動 | ← → 或 A D | 畫面下方 ◀ ▶ |
| 跳躍 | 空白鍵、↑ 或 W | 「跳」按鈕 |
| 暫停 | Esc 或 P | 右上角 ⏸ |

- 🍖🐟🍩🍓 **食物**：吃下即時加速。連續吃不被撞可累積 COMBO（最多 ×5）。
- 🌈 **彩虹加速板**：踩上去短暫加速。
- ⚠️ **障礙物**：三角錐、欄架、石頭可以跳過；木箱堆和滾動的大球太高，只能避開；泥漿會令你減速。
- 撞到障礙物會暈眩減速，並扣分。
- 分數 = 跑過的距離 + 食物 + 漂亮跳躍 + 名次獎勵 + 時間獎勵。最高分會儲存在瀏覽器。

## 角色

| 角色 | 特點 |
|---|---|
| 冬菇（紅貴賓） | 跳得最高，各方面平均 |
| 墨墨（英短） | 最高速度和加速倍數最高，但轉彎較慢 |
| 粉粉（美短） | 起步加速最快，轉彎最靈活 |

## 檔案

```
index.html   頁面骨架（選角、HUD、結果畫面）
style.css    介面樣式
game.js      Three.js 場景、角色動畫、電腦對手、障礙物、食物、計時計分
audio.js     Web Audio 即時合成：輕快背景音樂、觀眾歡呼和掌聲、音效
assets/      角色圖片（已去除邊緣雜色）、勝利畫面、Game Over 畫面
```

角色是一張圖片，但在 3D 場景中以頂點著色器即時變形：四肢交替擺動、尾巴搖動、身體起伏，配合彈跳、壓扁拉伸、傾側和跳躍動作，令角色在跑道上「跑」起來，而不是一張不動的圖。
