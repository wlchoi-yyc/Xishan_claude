# 始得西山宴遊記：尋找柳宗元

以柳宗元《始得西山宴遊記》為文本依據的**第一人稱立體網頁遊戲**。

> 柳宗元今天又出遊了，但遲遲未歸。你要循着他留下的痕跡，找出他的去向。

遊戲一開始**不會**告訴學生「去西山找柳宗元」。學生循着線索追蹤，完成整個遊戲時，其實已經親自重建了文章的**遊蹤、活動、景物和心境變化**，並經歷全文最重要的結構：**未遊西山 → 始遊西山**。

## 如何開啟

遊戲是純靜態網頁（HTML + JavaScript + Three.js），不需要安裝任何東西，但因為使用 ES 模組，**必須經由網頁伺服器開啟**（直接雙擊 `index.html` 會被瀏覽器阻擋）。

- **GitHub Pages（建議）**：在 GitHub 倉庫的 *Settings → Pages* 選擇此分支的根目錄，即可得到一個網址給學生使用。
- **本機**：在資料夾內執行以下任何一個指令，然後開啟 `http://localhost:8000`
  - `python3 -m http.server 8000`
  - `npx http-server -p 8000`
- **離線單檔版**：執行 `npm run build`（需要 Node.js）後，`dist/` 資料夾內的 `index.html` 可直接雙擊開啟。

Three.js 已放在 `lib/`，毋須連接網絡（只有書法字型會嘗試從 Google Fonts 載入，失敗時自動使用系統字型）。

### 操作

### 教師：章節選擇

標題畫面下方的「教師：章節選擇」可直接跳到任何一關；亦可在網址後加 `?ch=N`（N = 0–9），例如 `index.html?ch=7` 直接由西山之頂開始。

## 遊戲流程

| 關卡 | 地點 | 玩家主要任務 | 對應文本重點 |
|---|---|---|---|
| 序章 | 永州居所 | 搜查房間、接受「尋找柳宗元」任務 | 僇人、恆惴慄 |
| 第一關 | 永州山林 | 在高山、深林、迴溪、幽泉、怪石尋找舊痕跡；推理題 | 施施而行，漫漫而遊 |
| 第二關 | 山林深處 | 找出五種痕跡，排序重建平日遊山，觀看情景重現 | 披草、飲酒、醉臥、夢、歸；皆我有也 |
| 第三關 | 法華西亭 | 坐下眺望，鏡頭第一次對準西山時音樂改變 | 望西山，始指異之 |
| 第四關 | 湘江—染溪 | 問僕人、看地圖選渡口、乘船過江、以箭嘴判斷「緣」 | 過湘江，緣染溪 |
| 第五關 | 西山山腳 | 搜查痕跡、取得斧頭和火把，親手砍灌木、拖動火把燒茅草 | 斫榛莽，焚茅茷 |
| 第六關 | 西山山腰 | 選擇可靠的落腳點攀爬；途中回頭俯瞰 | 攀援而登，窮山之高而止 |
| 第七關 | 西山頂 | 點擊景物重建所見之景；轉身一周 | 岈然窪然、尺寸千里、縈青繚白、四望如一、特立 |
| 第八關 | 山頂 | 比較兩幅畫面，選「理解卡」 | 悠悠乎與灝氣俱…… |
| 第九關 | 山頂黃昏 | 循腳印找到柳宗元；他不想下山，邀你並肩坐下 | 引觴滿酌、蒼然暮色、猶不欲歸 |
| 終章 | 精神之境 | 不設測驗的「冥合」體驗；「你找到我了嗎？」 | 心凝形釋，與萬化冥合；遊於是乎始 |

### 設計重點

- **第一人稱視野**：全程以第一人稱鏡頭進行；僕人、船家、柳宗元說話時會轉頭、轉身**看着鏡頭**。
- **「柳宗元心境」系統**：左上角的「心」由「拘束／惴慄」（被繩綁住、顫抖）一路變化為「借遊排遣 → 自以為遊遍 → 驚異 → 興致勃發 → 開闊 → 悠然 → 心凝形釋」。
- **在遊戲環境中教文言**：「緣」用箭嘴方向判斷；「斫」「焚」親手操作；「尺寸千里」以鏡頭拉近呈現；「自遠而至」以暮色由遠而近吞沒景物呈現。
- **「與萬化冥合」不用問題教**：坐下後介面、任務、指南、心境圖示逐一消失，約十秒完全不能操作，只剩風聲、水聲、鳥聲與柳宗元的低語。
- **在山頂，柳宗元直接告訴玩家他仍不想回家**，並邀請玩家一起坐下，感受人與天地合而為一。
- **隱藏主題**：「尋找柳宗元」，也是柳宗元在西山重新找到自己。
- **結局**：顯示「未遊西山／始遊西山」的遊記重建表，以及標亮了玩家親身重建句子的原文。

## 檔案結構

```
index.html            頁面骨架
css/style.css         介面樣式
lib/                  Three.js（MIT 授權）
js/main.js            標題畫面與章節流程
js/engine.js          渲染、第一人稱鏡頭、移動、點擊互動、補間動畫
js/world.js           地形、樹木、人物、器物等程序化建模
js/ui.js              對話、原文字幕、心境、日誌、地圖、各種解謎介面
js/audio.js           程序化聲音（風、水、鳥、古琴式撥弦音樂），無需音檔
js/data.js            原文、心境、結局重建表
js/chapters/*.js      各章節
```

所有景物與聲音皆由程式即時生成，沒有外部美術或音效檔案。
