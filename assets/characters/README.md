# 柳宗元立體角色

`liu-zongyuan.glb`（約 3.2MB）由老師提供的 Tripo 模型（`Liuidle3dmodel.glb`，13.4MB）經 `tools/liu-model/build.py` 處理而成：

- **骨架**：Mixamo 標準 65 節骨架，關節位置正確，沒有更動骨骼。
- **蒙皮修正**：原模型的腰帶和整條長袍幾乎全綁在大腿骨上（髖骨只佔約 3%），左右亦不對稱，坐下時腰帶會被大腿拉走、走路時衣襬會在兩腿之間裂開。現已把長袍重新分配：腰部跟髖骨，下襬由左右大腿／小腿平滑過渡（中線兩側各 7.5 厘米漸變），12,817 個頂點受影響，手臂、頭部、鞋子不變。
- **貼圖壓縮**：原本三張 4096×4096 貼圖（佔顯示記憶體約 200MB，平板／手機容易卡頓）改為 2048 顏色貼圖＋1024 法線貼圖；金屬／粗糙度貼圖幾乎是常數，改用材質參數。
- **單一網格、38,625 個三角形**（舊 Blender 模型為 13 個網格、54,670 個三角形）。

## 口部張合

原模型沒有口部骨骼或表情。`build.py` 加入形變目標 `MouthOpen`（560 個頂點：下唇、下巴連鬍子向下約 1 厘米，上唇略向上），並在顏色貼圖沿唇線畫一條深色細線——閉口時是唇縫，張口時拉闊成口部陰影。`liu-character.js` 在柳宗元說話（`E.speaker` 為他的名字）時按說話節奏張合，其餘時間閉口。

## 劇情動作（烘焙在 GLB 內）

| 動作 | 用途 |
|---|---|
| Idle | 端正站立，只有輕微呼吸。肩膀保持模型原本高度，上臂由 A 字姿勢自然垂下、手肘微曲（舊版沿用 Tripo 待機，鎖骨下垂 23°、手肘向內屈，肩膀看來塌陷變形，已改正） |
| Walk | 雙手自然輕擺、步伐從容的「施施而行」（第二關情景重現） |
| Talk / SeatedTalk | 站着或坐着說話，雙手都不動，只有呼吸和輕微點頭 |
| SitDown / StandUp | 屈膝蹲低再盤膝坐下；反向站起 |
| SeatedIdle | 正襟危坐於平頂石上：大腿稍向下斜、小腿垂直放下、雙腿併攏；雙手自然垂在身旁，與站立時相同，只稍屈手肘令手在石面之上約 1 厘米（不放在腿上：放在腿上的手掌像在彈琴）；只有輕微呼吸。石頭由 `liu-character.js` 在坐姿時顯示（石面 0.44 米）|
| Drink | 掌心托杯舉到唇前（0→1）、手掌後傾杯口貼唇飲酒（1→2），由劇情 `drinkPose(k)` 控制 |
| LieDown / LyingIdle | 由坐姿向後躺下，右臂枕頭（醉則更相枕以臥） |
| Invite | 左手向身旁攤開——「坐下來吧」 |
| PointFar | 伸手指向遠方——「看看這山，看看遠處的水」 |
| DrunkSway | 身體不動，約五秒內緩緩垂下頭——「頹然就醉」 |
| Bow | 手臂完全不動，只有上身前傾致意（終章，玩家選 C 後） |
| GazeIdle | 站立遠眺，雙手自然垂下（終章，「直到今天才知道——」） |

`js/liu-character.js` 負責載入、獨立骨架複製、姿勢轉換、手勢（`gesture()`）、指定待機（`setIdle()`）、握杯及轉頭望向鏡頭。載入失敗或超過八秒時，改用 `js/people.js` 的程式人物。

所有動作都避免雙手互相接觸（拱手、負手、交疊），因為自動生成的手部蒙皮在這些姿勢容易變形。

設計原則：站得端正、不動聲色是古代有教養文人的表現，身子多動反顯浮躁。劇情中不播放坐下、站起、躺下的過渡（`setPose(pose, { instant: true })`），第二關以人影淡出淡入轉換姿勢；SitDown／StandUp／LieDown／Drink 片段仍保留在模型內但劇情不使用。

## 坐姿長袍（形變目標 SeatFlat）

`tools/liu-model/seat_morph.py` 按坐姿計算長袍的形狀，存成形變目標 `SeatFlat`；`liu-character.js` 在坐好時把它開到 1，站起或躺下時收回。它做三件事：

1. **撫平布面**：長袍站立時的直摺紋和前襟幾層重疊的布邊，坐下後在大腿上疊成一圈圈厚重的波浪。腰帶以下至下襬之上的淺色布面，逐點以周圍 12 厘米的布面擬合平順曲面再投影上去（重疊的布層合成一片），並重算法線；腰帶垂下的深色帶子不參與擬合，跟着下面的布面移動、浮在面上。
1b. **貼着大腿、垂進兩膝之間**：站立時長袍向前垂開的布量，坐下後被大腿抬起，堆在腿上像個大肚子。大腿上方的布面拉近到「大腿＋布料」的半徑（以大腿骨為軸，髖部約 9.5 厘米、膝部約 7.5 厘米）；兩膝之間的布向下垂約 9 厘米，從正面看得出兩個膝頭；膝下垂下的衣襬向中間收窄約四分之一，不再圍成一個大鐘形。
2. **貼平石面**：臀下長袍底面壓平在 0.44 米石面上，臀部後方沒有空隙。
3. **貼圖**：Tripo 的顏色貼圖和法線貼圖畫上了摺紋陰影；這段淺色布面的貼圖去掉大範圍明暗，只留布紋（深色衣邊和帶子不改）。站立時摺紋仍由網格本身呈現。這一步只做一次（記錄在 GLB 的 `asset.extras.seatTextureFlattened`）。

改動坐姿後要重新執行（可重複執行，舊的 SeatFlat 會被取代）：

```
python3 tools/liu-model/seat_morph.py assets/characters/liu-zongyuan.glb
```

## 手不會陷進衣服

`anims.py` 會按每個姿勢計算長袍實際的蒙皮位置（`skin_points`），再調整手的位置：站立時把手臂稍為張開，直至手離衣服側面約 1 厘米；坐着時雙手沿用站姿垂下，逐步稍屈手肘，直至手不碰到石面。

## 重新產生

```
python3 tools/liu-model/build.py 原始Tripo模型.glb assets/characters/liu-zongyuan.glb
```
需要 Python 3、numpy、Pillow。原始 Tripo 骨架模型不在倉庫內：只改動作（`anims.py`）時，用
```
python3 tools/liu-model/rebuild_anims.py assets/characters/liu-zongyuan.glb
```
直接更新遊戲中的 GLB（網格、蒙皮、口部形變、貼圖原封不動，約需五分鐘）。動作定義在 `tools/liu-model/anims.py`（以角色座標描述每節骨骼的轉動，手部位置以簡單 IK 搜尋）。`tools/liu-model/view.html?clip=Drink&t=0,1.25,2.5&views=front,side` 可經網頁伺服器預覽任何動作。

# 老僕（old-servant.glb）

序章的老僕。原始 Tripo 模型沒有骨架，由 `tools/servant-model/build_servant.py` 自動綁骨：

- 按模型比例放置 Mixamo 式骨架（骨骼名稱 `mixamorig:*`，與柳宗元共用同一套動作工具）。
- 蒙皮權重以頂點到骨段的距離計算，再按部位限制（手臂、頭、褲管、衣襬、軀幹），衣襬用與柳宗元長袍相同的髖↔腿平滑分配，最後沿網格平滑三次。
- 原模型沿貼圖接縫把同一位置的頂點分成幾份，這些頂點的權重會取平均、完全一致；否則轉頭或說話時接縫兩邊移動不同，臉上會被撕出一道道裂痕。現有的 GLB 已用 `tools/servant-model/weld_weights.py` 修正。
- 口部：形變目標 `MouthOpen`（下唇、下巴、鬍子下移），並在貼圖上畫出唇縫；說話（`E.speaker === '老僕'`）時張合。
- 去掉原檔的高光擴充（會令衣服出現白斑），貼圖壓縮為 2048／1024 JPEG。

動作：`Idle`（微駝、輕微呼吸）、`Talk`（呼吸加輕微點頭）、`Bow`（只彎上背和頸，雙臂反向補償，手不動）。原模型雙手垂在身旁、與衣服相連，因此所有動作都不移動手臂，避免撕裂衣服。序章結束時老僕欠身相送。

遊戲中由 `js/servant-character.js` 載入（標題畫面時預先載入，載不到便用程式繪製的人物）。貼圖分塊很碎，遠看時 mipmap 會把深色衣料混進臉上，所以老僕的貼圖不用 mipmap。

```
python3 tools/servant-model/build_servant.py 原始Tripo模型.glb assets/characters/old-servant.glb
```
